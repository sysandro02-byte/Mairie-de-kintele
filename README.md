# Mairie de Kintélé — Portail municipal

Site institutionnel moderne de la commune de Kintélé, République du Congo.

## Stack
- Next.js 15
- React 19
- TypeScript
- CSS responsive sans dépendance UI lourde
- Déploiement cible : Vercel

## Pages
- Accueil
- Démarches
- Ma commune
- Actualités
- Contact
- Sources & crédits
- Mentions légales
- Accessibilité

## Développement
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Les contenus factuels sont sourcés et les visuels sont issus de Wikimedia Commons sous licences compatibles.
